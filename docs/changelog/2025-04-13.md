## Route groups y layout del workspace

- Se reorganizo `app/` con route groups: `(auth)/` para login/register, `(workspace)/` para la app autenticada
- Se creo `app/(workspace)/layout.tsx` con el sidebar compartido — todas las paginas dentro de `(workspace)/` lo heredan automaticamente
- Se creo `app/(workspace)/home/page.tsx` — solo el contenido de la pagina, minimo
- Los route groups usan parentesis `()` para que no afecten la URL: `/home` en vez de `/workspace/home`

## Sidebar con Shadcn

- Se instalo el componente Sidebar de Shadcn (`npx shadcn@latest add sidebar`)
- Variante `inset` para aspecto moderno
- Header: logo "Lumma"
- Content: enlaces de navegacion con iconos (Lucide React) y `Link` de Next.js
- Footer: nombre del usuario + boton de cerrar sesion (server action con form)
- `SidebarTrigger` para colapsar/abrir (tambien con Ctrl+B)

## .env.example

- Se creo `apps/web/.env.example` como plantilla de variables de entorno
- Los secretos nunca se suben al repo (`.env.local` esta en `.gitignore`)
- Para montar en otra maquina: `cp apps/web/.env.example apps/web/.env.local` y rellenar los vacios
